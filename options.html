How to get an API key

  1. Go to the Google Cloud Console
  2. Create a new project (or select an existing one)
  3. Enable the PageSpeed Insights API
  4. Create credentials → API Key
  5. (Recommended) Restrict the key to the PageSpeed Insights API
  6. Copy the key and paste it above

The key is stored locally in Chrome using chrome.storage.sync. It is never sent anywhere except directly to Google's PageSpeed Insights API. See the included README.md or GETTING-STARTED.md for a full guide with screenshots.
